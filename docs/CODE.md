# Arquivo de contexto desenvolvimento

## Commits
- nunca realize pushes, apenas realize os commits locais de acordo com a tarefa realizada. Exemplo: se foi pedido uma feature, ao realizar ela, faça o commit. Exemplo B: caso a task seja muito grande, realize commits parciais que façam sentido
- As mensagens de commits devem seguir as convenções de:
  - feat: para features
  - test: para testes integração/unitários
  - fix: correções de bugs
  - refactor: refatorações
  - etc
- Além disso, as mensagens de commit devem ter o prefixo `refs #001 (número do commit) - feat: feature example`
- O número do commit é determinado pela quantidade de commits feitos na aplicação
